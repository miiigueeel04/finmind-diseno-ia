# FinMind: asistente de finanzas personales con IA generativa

Trabajo final del curso de IA Generativa (UPM). Es un **documento de diseño**:
describe la arquitectura de un asistente conversacional de finanzas personales,
con RAG, tool-use, memoria conversacional, plan de evaluación y medidas de
seguridad y privacidad (RGPD, PSD2).

**No incluye implementación**: es un trabajo académico de diseño.
